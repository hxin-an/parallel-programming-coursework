# HW 4 — MPI Communication Patterns

Distributed implementations that compare collective, point-to-point, tree-reduction, and one-sided communication patterns.

## Contents

- `src/part1/` — Monte Carlo π using gather, reduce, blocking/non-blocking communication, and MPI RMA
- `src/part2/` — distributed matrix multiplication
- `src/ping_pong.c` and `src/one_side_example.c` — communication micro-examples

The source is kept as a reviewable implementation snapshot. Compilation requires an MPI toolchain and the original assignment harness where applicable.

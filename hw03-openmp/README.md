# HW 3 — OpenMP Graph and Numerical Kernels

Shared-memory parallelization of breadth-first search, PageRank, and conjugate gradient.

## Highlights

- Parallel frontier construction for BFS
- OpenMP reductions and scheduling for PageRank
- Parallel sparse matrix-vector and vector operations for conjugate gradient

The three submitted implementations are under `src/`. They depend on the course graph and matrix interfaces, which are not included.
